# png2ico

# 画像 ➔ ICO アイコン変換ツール 🎨

一般的な画像ファイル（PNG、JPG、BMP、WebPなど）を、Windowsなどで広く使われるアイコン形式（`.ico`）に一発で変換できるシンプルなデスクトップツールです。

Pillowの機能を活かし、Windows標準の**マルチサイズ（16x16 〜 256x256）に対応した高品質なICOファイル**を自動生成します。

---

## 🔥 主な機能

* 🖼️ **幅広い入力フォーマット**: `.png`、`.jpg`、`.jpeg`、`.bmp`、`.webp` などの主要な画像形式に対応。
* 📦 **マルチサイズICO自動生成**: 1枚のアイコンファイルの中に、Windowsで必要な複数の解像度（16x16, 32x32, 48x48, 64x64, 128x128, 256x256）を自動で内包。
* 📁 **前回フォルダの記憶**: ファイル選択や保存時に、最後に開いたディレクトリを自動で記憶（`~/.icoconverter/settings.json`）。次回からのファイル選択がスムーズになります。
* 🔒 **PermissionError対策**: 設定ファイルをユーザーのホームディレクトリ配下に保存するため、管理者権限のない環境でも安全に動作します。
